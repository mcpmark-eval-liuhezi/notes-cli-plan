# notes-cli-plan

`notes-cli` is a small personal command-line tool that turns the Markdown reading notes I accumulate into clean, self-contained HTML pages. Point it at a notes directory or a single file, and it converts each note into a tidy, styled HTML page — readable headings, preserved links and emphasis, and no manual cleanup — so the notes are easy to browse, share, and archive. This repository (`notes-cli-plan`) is the planning side of the project: a single place to point people at, holding the roadmap, the tracking issue, and status updates before any code is written.
